{% translate "Images Vigil can't fetch for you" %}

{% translate "These need something Vigil doesn't have — a subscription, or a pipeline that isn't built yet. Both buttons set up the form below; you supply the file." %}

{% blocktranslate %}RHEL proper needs an active Red Hat subscription — Vigil cannot fetch it anonymously the way it fetches the catalog images above. Get the ISO yourself from a source you're entitled to use, then either upload it below or, if it's already hosted somewhere Vigil's server can reach, paste the URL and its SHA-256 instead. Legitimate source: Red Hat Customer Portal.{% endblocktranslate %}
{% blocktranslate %}Windows images can't be imported yet — Vigil extracts a PXE kernel/initrd pair from the ISO, and a Windows installer needs a different pipeline (boot.wim/bootmgr) that doesn't exist here yet. Support for it is planned; until then, uploading or pulling a Windows ISO is refused rather than accepted and failed after the transfer.{% endblocktranslate %}
